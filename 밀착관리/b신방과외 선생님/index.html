신방 학년별 특징

학생들은 수업이 끝난 뒤 스스로 복습 시간을 마련해 이해도를 점검해요. 교재에 제시된 핵심 문항을 풀고 틀린 부분을 다시 확인하면서 학습 흐름을 잡아가죠. 주제와 소재를 구분해 정리하면 기억이 오래 남고 응용 문제에서도 자신감이 생겨요. 신방은 아파트가 많아 이동 시간이 짧아 집중 학습에 유리한 환경을 제공해요. 이런 습관을 꾸준히 유지하면 교과서 수준을 넘어선 사고력도 키울 수 있답니다.

초등 고학년은 자기주도 학습 성향을 평가해 과제 방식을 맞춤형으로 제공하고, 문제 해결 과정을 기록하도록 지도해요.
중학생은 주 2회 90분 수업에 개념 리뷰 20분을 넣어 핵심을 재정리하고, 실전 문제 풀이로 응용력을 강화해요.
고등학생은 전 과목을 포괄하는 과외 활용으로 심화 학습과 시험 대비 전략을 동시에 잡아줘요.
전체 학년은 학생 케이스 기록 시스템을 도입해 학습 후 무엇을 느꼈나에 집중하는 피드백을 제공하고, 교과 너머 흐름을 이해하도록 사고력 기반 학습을 구현해요.
